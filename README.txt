HƯỚNG DẪN ĐĂNG GITHUB PAGES

1. Giải nén ZIP.
2. Tạo repository GitHub Public.
3. Tải TOÀN BỘ nội dung bên trong thư mục lên thư mục gốc repository (index.html, games, assets, .nojekyll).
4. Settings > Pages > Deploy from a branch > main > /(root).
5. Chờ GitHub Pages triển khai và mở URL được cung cấp.

Lưu ý: Internet cần thiết để tải thư viện Tailwind, Font Awesome, Google Fonts, flipbook và kết nối Apps Script. Tài liệu Drive vẫn ở Drive. Không đổi đường dẫn hoặc tên thư mục assets/games.
